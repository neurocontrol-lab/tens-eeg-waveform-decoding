E016: one-versus-rest waveform detection

2 November 2026 · Task 4 · participants 3–12 · separate first/second presentations

100 exploratory binary detectors, plus 55 strict-reference detectors. Each uses the same 100 selected features as its E015 parent fold and binary shrinkage LDA with equal target/rest priors. No new feature selection, spatial fitting or threshold tuning.

Features include voltage, slope, curvature, alpha/beta power and saved xDAWN components over 50–1,050 ms. Tests hold out complete waveform comparisons, keep pairs together, and preserve the 15.312-second train/test trigger separation. Five binary probabilities are independent outputs and need not sum to one.

Metric distinction: balanced accuracy uses the fixed 0.5 threshold on held-out predictions. Within-comparison AUC compares positives and negatives only within the same fitted fold model, weighted by the number of positive–negative pairs. It excludes single-class test comparisons. Pooled AUC also compares scores across different fold models and is retained as a diagnostic, not an interchangeable estimate. These estimates do not establish statistical significance; no permutations have been run.

Mean exploratory balanced accuracy is below the 50% reference, while within-comparison AUC is close to 0.50. There is no clear overall gain from switching to the binary formulation. No score directions were reversed after inspecting results.

Support and provenance

Targets have only 3–21 held-out positives per participant/position. Participant 12, first-position Square has one fold with no training positives: that fold uses a flagged constant-negative fallback and its errors remain in the score. Single-class test-fold AUC is undefined. A total of 1,549 LDA fits and one fallback cover 1,550 detector-folds.

All 155 detector metrics were recomputed from saved predictions. All 310 parent folds reproduced E015 scaling and used exactly 100 features. Frozen source/input hashes were checked. The full numerical run and fitted parameters remain local and ignored by Git.

Formal inference requires an appropriate full-pipeline null, including label-dependent feature selection and spatial fitting, plus multiple-comparison control. Current-monitor timing remains unverified. Reusing E015 features answers whether a binary model helps with this representation; it does not evaluate target-specific selection.
