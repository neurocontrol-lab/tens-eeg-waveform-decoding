Waveform decoding after nominal-charge adjustment

Nominal charge uses the true waveform shape. The waveform-specific variant also uses the true waveform to select the slope. These comparisons measure sensitivity to a label-informed adjustment.

Held-out performance

Scores average participants equally. Balanced accuracy is mean class recall, with a five-class reference of 20%. Changes compare each adjustment with the original EEG in the same window. Intervals are descriptive paired participant bootstrap intervals.

The charge and correction controls have one fixed value or vector per waveform within a participant. Their zero within-class covariance makes shrinkage LDA degenerate. Nearest-centroid scores on the same folds show which templates can be distinguished.

Confusion matrix

Rows show the delivered waveform. Columns show the predicted waveform. Cells show mean within-participant row percentages. The diagonal is recall.

Nominal charges shared by waveform pairs

Equal nominal charges produce identical pooled correction vectors within a participant. Waveform-specific slopes can produce different vectors even when nominal charges match.

Methods and coverage

WD-001 voltage features used 14 electrodes and nine 50 ms bins. Post-stimulus features span 50 to 500 ms and matched pre-stimulus features span −500 to −50 ms. All comparisons reuse the original comparison-held-out folds and the same shrinkage LDA with training-fold standardization. First- and second-presentation scores use subsets of those held-out predictions.

Nominal cathodic charge equals peak amplitude × 0.4 ms × the ideal waveform area factor. The Task 4 CSV records one amplitude per pair. Its value was constant for every participant and second waveform, so the lookup uses that association for both presentations. Delivered current remains unverified.

Charge-only slopes were frozen from Task 3 and applied as −slope × nominal charge, with reference charge zero. The exact post-stimulus correction vectors were also applied to matched pre-stimulus EEG. The charge-only control uses the scalar. Each correction-only control uses the corresponding vector without EEG.
